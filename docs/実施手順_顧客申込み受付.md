# 実施手順（かんたん版）: 顧客申込み受付・ヒアリング調整

最終更新: 2026-08-03
対応する詳細仕様書: `msp-customer-portal/docs/運用手順書_顧客オンボーディング統合フロー.md` 手順0

## これは何の作業か

Webサイトの申込みフォーム（`/apply.html`）から届いた新規申込みに対応し、ヒアリング（Web会議）でプラン・IPレンジ等を確定させるまでの作業。ここが完了したら、[実施手順_顧客オンボーディング統合フロー.md](実施手順_顧客オンボーディング統合フロー.md)の手順0（顧客ID割り当て）以降に引き継ぐ。

## 始める前に

管理画面（`/admin/customer-applications.html`）はGoogle Workspace（atlib.jpアカウント）でログインする（2026-08-25〜）。事前準備は不要で、初回アクセス時に自分のGoogleアカウントでログインするだけでよい。

以降は手順1〜4を上から順に実施すればよい。エラーが出た場合のみ[うまくいかない場合](#うまくいかない場合)を参照する。

---

## 手順1: 新着申込みに気づく

1. **操作**: 新規申込みがあると、`sales@atlib.jp`宛に件名「【新規申込み】〇〇株式会社 様」というメールが自動で届く
2. **操作**: メール本文末尾の「詳細を管理画面で確認: https://...」のリンクをクリックする（未ログインの場合はGoogleログイン画面に転送されるので、自分のatlib.jpアカウントでログインする）
3. 上記リンクを使わない場合は、ブラウザで `https://portal.atlib.jp/admin/customer-applications.html` を直接開いてもよい（一覧画面が表示される）

## 手順2: 内容を確認し、対応状況を「連絡済」に更新する

1. **画面**: 一覧画面で対応状況が「未対応」になっている行をクリックし、詳細画面を開く
2. **確認**: 会社名・担当者名・メール・電話番号・興味のあるプラン・ご要望備考を確認する
3. **操作**: 記載された連絡先（メール・電話）へ連絡し、ヒアリング（Web会議）の日程を調整する
4. **操作**: 詳細画面の「対応状況」プルダウンで**「連絡済」**を選び、「保存する」ボタンを押す
5. 日程が確定したら、同じ手順で対応状況を**「ヒアリング予定」**に更新しておく（必須ではないが、他の担当者が見た時に状況が分かるようにするため）

## 手順3: ヒアリング（Web会議）を実施する

1. **操作**: Web会議で、顧客のネットワーク環境・監視対象機器のおおよその台数・希望プランを確認し、以下を確定させる

   | 確定させる項目 | 例 |
   |---|---|
   | `company_name`（正式名称） | `atLIB株式会社様` |
   | 連絡先メールアドレス | |
   | プラン名 | `エントリープラン` |
   | 顧客のネットワークのIPレンジ | `192.168.1.1-254` |
   | SNMP監視対象機器のおおよその台数 | 50台が目安の上限。超えそうな場合は担当エンジニアに相談 |

2. **注意**: 監視対象機器が50台を超えそうな場合は、標準構成では対応できない可能性があるため、実施手順に進む前に担当エンジニアに相談する

## 手順4: 対応状況を「完了」にし、次の作業に引き継ぐ

1. **操作**: 詳細画面の「対応状況」プルダウンで**「完了」**を選び、「保存する」ボタンを押す
2. **操作**: [実施手順_顧客オンボーディング統合フロー.md](実施手順_顧客オンボーディング統合フロー.md)を開き、手順0（顧客マスタで顧客IDを割り当てる）から作業を続ける。手順3で確定した項目（company_name・連絡先・プラン名・IPレンジ・機器台数）はそのままそちらの「始める前に」の表に使う

## うまくいかない場合

### 管理画面（`/admin/customer-applications.html`）にログインできない

「このアカウントには管理画面へのアクセス権限がありません」と表示される場合、ログインしたGoogleアカウントがatlib.jpドメインのものになっているか確認する（個人のGmailアカウント等でログインしていないか）。それでも解決しない場合は担当エンジニアに連絡する。

### 通知メールが届かない

- 迷惑メールフォルダを確認する
- それでも見つからない場合は、`/admin/customer-applications.html`を直接開いて一覧に新着が出ているか確認する（メール送信自体は失敗してもフォーム送信そのものは正常に記録される仕組みのため、一覧には出ているはずである）
- 一覧にも出ていない場合は、担当エンジニアに連絡する

### 一覧画面が真っ白・エラーが出る

ページを再読み込みする。改善しない場合は担当エンジニアに連絡する。
